In order to play these files you need a copy of Sonic Pi 2.11 or later

You also need a copy of the Sonatina Symphonic Orchestra which can be downloaded from
http://mattiaswestlund.net/samples/sonatina-symphonic-orchestra-1.0.zip

Unzip the file and place on your desktop, renaming the top folder to SSO. Otherwise leave the structurew intact.

The previous program GoBetweenAndVariation.rb accesses the two large files which play the code.

They are too long to play directly in a Sonic Pi buffer, but instead use the run_file command ingtroduced in SP 2.11

Mine were stored in a path ~/Documents/SPfromXML/ If your path is differnt then alter this file accordingly.
