If you want to use the same patches on the Arturia MatrixBrute you can download a file containing them from
http://r.newman.ch/rpi/mesmericarpeggios.mbprojz.zip

They need to be loaded into positions p1..p10 using Arturia's Midi Control Center

YOu can hear the audio output of the mesmerric arpeggios program at
https://soundcloud.com/user-999157198-370666210/mersmericarpeggios

YOu can view a video talking about the program at https://youtu.be/sVVt3EXJJyo
