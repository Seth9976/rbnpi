The file index.xml is utilised by TouchOSC. save the file as index.xml then compress or zip it 
and rename the resulting file testControl.touchosc
This file should then be opened by the free TouchOSC editor (available for Mac, PC or Linux) 
and sync it to the (purchased) TouchOSC app for your IOS or Android phone or tablet.
Setup instructions ar contained in the article on rbnrpi.wordpress.com
